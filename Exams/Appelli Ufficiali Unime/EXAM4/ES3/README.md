# Esercizio 3 (5 Punti) - Logica di Base


1. Definire la classe `Convertitore`.
2. Al suo interno definire il metodo `converti`, invocabile senza creare un oggetto, che riceve un valore espresso in chilometri (intero) e restituisce il suo equivalente in metri (intero).

## Output atteso

```text
converti(1)   ->  1000
converti(0)   ->  0
converti(7)   ->  7000
converti(-3)  ->  -3000
```
