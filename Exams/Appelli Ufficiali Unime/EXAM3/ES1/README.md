# Esercizio 1 (5 Punti) - OOP di Base (Interfacce)


1. Definire l'interfaccia `Figura`, che dichiara il metodo `area`, il quale restituisce un numero con la virgola.
2. Definire la classe `Rettangolo`, il cui costruttore riceve nell'ordine la base e l'altezza.
3. Definire la classe `Quadrato`, il cui costruttore riceve la misura del lato.
4. Entrambe le classi realizzano il contratto dichiarato da `Figura`.
5. Tutte le variabili d'istanza devono essere private.

## Output atteso

```text
area di Rettangolo(3.0, 4.0)  ->  12.0
area di Quadrato(3.0)         ->  9.0
```

Gli oggetti devono poter essere raccolti e usati attraverso il tipo `Figura`.
